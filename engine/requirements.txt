# IMPORTANT — Python version: use Python 3.13, not 3.14, for this project.
# PyAudio (below) has no official Windows wheels for 3.14 yet (confirmed as
# of Aug 2026 — check https://pypi.org/project/PyAudio/#files if this may
# have changed since) and falls back to a source build that needs
# portaudio.h, which isn't available either. There's a maintained fork
# (PyAudioWPatch) with 3.14 wheels, but its import name is "pyaudiowpatch"
# not "pyaudio", so it's not a drop-in — both this codebase
# and the SpeechRecognition library itself do "import pyaudio" directly,
# so swapping would mean monkey-patching sys.modules, which is fragile.
# Simplest fix: install Python 3.13 alongside 3.14 (side-by-side installs
# are fine) and create this project's venv with it, e.g.:
#   py -3.13 -m venv venv
#   venv\Scripts\activate
#   pip install -r requirements.txt
# Everything else in this file (pygame-ce, etc.) works fine on
# either 3.13 or 3.14 — this is specifically a PyAudio-on-3.14 gap.
